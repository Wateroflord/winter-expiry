# Просрочка (winter-expiry)

Android-приложение для кассира: учёт сроков годности на полках **Вода / Пиво / Энергетики**.

## Что умеет
- 3 раздела, в каждом кнопка **+** (добавить вручную) и кнопка **сканера** (сразу камера).
- Сканируешь штрихкод → название и картинка подтягиваются из интернета (база Open Food Facts).
- Если товара нет в базе — вписываешь название сам, приложение **запоминает** штрихкод, и в следующий раз заполнит всё само, даже без интернета.
- Дата вводится быстро: `121126`, `12.11.26`, `12.11` — или через календарь.
- Количество штук, сортировка по дате (сверху то, что кончается раньше).
- Цвета: 🔴 просрочено, 🟠 скоро (за N дней, настраивается 1–7), 🟢 норм. На вкладках — счётчик проблемных.
- Кнопка **«Снято»** (или свайп вправо) → товар уходит в историю, можно отменить/вернуть.
- Уведомление раз в день в выбранное время (по умолчанию 9:00) со списком того, что пора проверить.
- Все данные хранятся на телефоне. В настройках — **резервная копия**: сохранить в файл (отправить себе в Telegram / на Google Диск) и восстановить.
- Ставится и обновляется через **Winter Hub**.

## Сборка
APK собирается сам на GitHub (Actions) при каждом пуше в `main`.
Готовый файл: вкладка **Releases** → `winter-expiry.apk`.

APK подписывается постоянным секретным ключом (секрет `WINTER_SIGNING`, общий скрипт `winter-hub/ci/sign_apk.py`), поэтому новые версии ставятся поверх старой без потери данных.
